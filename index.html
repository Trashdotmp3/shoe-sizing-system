Automatic Shoe Sizing System

Bachelor project website for automatic foot measurement, shoe size recommendation, brand-specific size comparison, product search, QR integration, and statistics collection.

Home Recommendation Brand Sizes QR Page Search Statistics

Project overview

This system combines an embedded foot measurement device with a web platform. The device measures foot length, determines the recommended shoe size, and transfers the user to the website through a QR code for further comparison, manufacturer-specific sizing, and shoe search.

Main system functions

  • Foot length based general shoe size recommendation
  • Manufacturer size comparison for Nike, Adidas, and New Balance
  • QR landing page for transition from physical device to website
  • Shoe product search by size, brand, category, and model
  • Statistics collection for measurements, QR scans, and search activity

System architecture

  • Embedded measuring device with IR distance sensor and LCD interface
  • Frontend website hosted from GitHub repository
  • Supabase PostgreSQL database for size charts, products, and statistics
  • Database-driven recommendation, comparison, and search workflow

User flow

1
Measure foot length

The user places the foot into the prototype device and the system measures the distance automatically.

2
Get a recommended size

The system calculates a general size recommendation and can adapt it to men, women, or kids categories.

3
Continue on the website

By scanning a QR code, the user opens the website and receives additional information about brand-specific sizes and available shoes.

4
Search and compare

The user can compare size charts, search for products, and use the website as a continuation of the measurement process.
