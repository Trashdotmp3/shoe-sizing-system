About the project

This website is part of an automatic shoe sizing system that measures foot length, recommends a general shoe size, and compares size recommendations across different brands.

Main functions

  • Foot length based size recommendation
  • Brand-specific size tables
  • QR code integration
  • Shoe search by size and brand
  • Statistics collection
